== A database written in Rust

FigDB is a database. The storage engine, the crash recovery, and the network protocol are written here, in Rust, instead of being borrowed from RocksDB, etcd, or a Raft library.

What runs today is one server. It keeps an on-disk log and sorted tables, and it speaks over TCP. That path is crash-tested. A write is acknowledged only after the log has been synced to disk. Copying data to other servers, and multi-statement transactions, are the next pieces. They are not in this tree yet.

Start with <<sec-introduction,Introduction>>, then <<sec-architecture,Architecture>>. Measured numbers are in `benchmarks/`. Where this prose and the code disagree, the code and its tests win.

=== Quick start

[source,bash]
----
cargo run -p fig-server --bin fig-server -- --dir /tmp/fig-srv --addr 127.0.0.1:7001
cargo run -p fig-server --bin fig-cli -- put k1 v1
cargo run -p fig-server --bin fig-cli -- get k1
./scripts/check.sh   # fmt --check + clippy -D warnings + full test suite
----
