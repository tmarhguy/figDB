This manual is the detailed technical reference for the project.
It is the companion to the concise, GitHub-facing `README.md`:

* `README.md` -- project identity, status, and quick start.
* `docs/` (this manual) -- architecture, interfaces, verification, and
  implementation detail in engineering-manual style.
* `docs/architecture/`, `docs/adr/`, `docs/correctness/`, `docs/testing/`,
  `docs/benchmarks/` -- prose notes, decision records, and measured
  results, linked from the chapters below rather than duplicated.

Conventions used throughout:

* `monospace` marks commands, file paths, identifiers, and literals.
* Unmeasured values are written as `TBD (unmeasured)` -- never estimated.
* When prose and code disagree, the code plus its tests win until the
  documentation is updated in the same milestone.
